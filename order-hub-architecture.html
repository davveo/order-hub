订单管什么

  • • 单据、状态机、金额快照、幂等
  • • Saga：优惠占用 → 账本冻结 → 落单 → 支付
  • • scene 插件：商城 / 积分 / 会员 / 课程
  • • 事件与超时关单、售后编排

怎么对接已有系统

  • • Auth：introspect → user_id，不信 body
  • • OfferHub：quote / reserve / commit / reverse
  • • Ledger：Freeze / Capture / Release / Credit
  • • 同一 tenant、最小金额单位、trace_id

明确不做

  • • 不做登录、优惠规则、余额内核
  • • 不做渠道路由与仓配主数据
  • • 不做 2PC；失败靠幂等补偿
  • • 不让 C 端直接改 PAID
